## 🚀 Deploy manual (Cloudflare Pages)

> **Importante**: Usar `wrangler` v2 con `pages publish` (NO `wrangler@latest pages deploy` porque detecta wrangler.toml del proyecto padre).

```bash
CLOUDFLARE_API_TOKEN=<token> \
CLOUDFLARE_ACCOUNT_ID=6fc12c9a89723c0039cf189380c0b02f \
npx wrangler@2 pages publish . --project-name=coporo --branch=main --commit-dirty=true
```

## 🔄 Redirect 301 desde dominio viejo

Cada HTML incluye un JS redirect al inicio del `<head>`:

```javascript
if (window.location.hostname === 'coporo.pages.dev') {
  window.location.replace('https://soluciones360.makeseo.app' + window.location.pathname + window.location.search);
}
```
